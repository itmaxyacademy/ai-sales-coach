## 1. Anti-Slop Audit Findings

Findings are grouped by rule severity: Hard Gate (HIGH), Purpose-Gate (MEDIUM), and Quality Locks / Hygiene (LOW).

### High Severity (Hard Gate Violations)

1. **HIGH - R-36, R-17: Pseudo-biometric LLM prompt and randomized output in facial analysis.**
   - Location: `Backend/src/services/facialService.ts` (Lines 168, 192-210)
   - Issue: The service truncates incoming webcam base64 images to only 200 characters (`[data:image/jpeg;base64,${imageBase64.slice(0, 200)}...]`) and sends this string to `gpt-4o-mini` as text. If the model returns `neutral`, it rolls `Math.random()` to simulate `enthusiastic`, `engaged`, or `confident` states, and uses `Math.random() > 0.3` to simulate eye contact.
   - Violation: R-36 (No fabricated claims) and R-17 (Data and numbers without verified source).
   - Recommendation: Remove backend pseudo-vision LLM calls. Rely on client-side MediaPipe landmark evaluation already computed in the browser, passing real geometric metrics in the session payload.

2. **HIGH - R-02: Em dash character (`—`) used across UI components and fallback utilities.**
   - Location:
     - `Frontend/lib/dateUtils.ts` (Lines 12, 15, 26, 34, 37, 58)
     - `Frontend/app/karyawan/history/page.tsx` (Lines 355-364)
     - `Frontend/app/karyawan/dashboard/page.tsx` (Lines 145, 148, 157, 188, 275)
     - `Frontend/app/admin/sessions/page.tsx` (Lines 134, 146, 154)
     - `Frontend/components/dashboard/SuperAdminDashboard.tsx` (Lines 417, 450)
     - `Backend/src/services/facialService.ts` (Line 220)
     - `Frontend/styles/globals.css` (Line 572)
   - Issue: `dateUtils.ts` exports `"—"` as the default placeholder for null dates, propagating em dashes to numerous tables and stat cards throughout the application.
   - Violation: R-02 (Forbidden em dash in UI copy and text).
   - Recommendation: Replace em dash fallback strings with a standard hyphen (`"-"`), `N/A`, or empty state labels.

3. **HIGH - R-26, R-32: Invisible wrapper flash on initial hydration in ThemeProvider.**
   - Location: `Frontend/components/ThemeProvider.tsx` (Lines 63-65)
   - Issue: The component renders `<div className="invisible">{children}</div>` before the client has mounted. This suppresses accessible content during server rendering and initial paint.
   - Violation: R-32 (Keyboard and screen-reader accessibility) and R-26 (Functional rendering).
   - Recommendation: Remove the invisible wrapper and let Next.js with `next-themes` manage theme attribute injection via standard class toggling.

### Medium Severity (Purpose-Gate Violations)

4. **MEDIUM - R-04: Emoji icons used as timeline event badges and log markers.**
   - Location:
     - `Backend/src/services/insightService.ts` (Lines 276, 280, 284: `Breakthrough Moment`, `Friction / Doubt`, `Objection Point` with emojis)
     - `Frontend/app/karyawan/session/[sessionId]/result/page.tsx` (Lines 352, 681)
   - Issue: While previous audit changes cleaned `SessionTimelineReplay.tsx`, emoji icons remain hardcoded in the insight service and the result screen.
   - Violation: R-04 (Generic AI decorative icons / emoji).
   - Recommendation: Use semantic text badges or Lucide SVG icons tailored to conversation milestones.

5. **MEDIUM - R-10, R-11: Trend stacking on the authentication page.**
   - Location: `Frontend/app/(auth)/login/page.tsx` (Lines 199, 209, 258)
   - Issue: The login card combines `backdrop-blur-2xl`, translucent borders (`border-white/15`), extreme border radius (`rounded-[2rem]`), and multi-layered radial gradients simultaneously.
   - Violation: R-10 (Glassmorphism overdose) and R-11 (Inconsistent border radius).
   - Recommendation: Simplify to a solid surface card adhering to standard design tokens (`var(--radius)`).

6. **MEDIUM - R-16: Mixed language copywriting.**
   - Location: `Frontend/app/(auth)/login/page.tsx`
   - Issue: Headings and value propositions are written in English ("Master sales conversations before meeting real clients", "Welcome Back", "Your email"), while helper texts and quick logins are in Indonesian ("Masuk dengan akun demo", "Pilih peran, lalu pilih akun dari perusahaan atau tim").
   - Violation: R-16 (Copywriting consistency).
   - Recommendation: Unify interface copy to a single primary language per locale setting.

### Low Severity (Quality Locks and Code Comment Hygiene)

7. **LOW - Code Comments: Decorative separator banners in source files.**
   - Location:
     - `Frontend/components/ui/index.tsx` (e.g., `// ── PageHeader ──────`)
     - `Frontend/components/Aiavatar3d.tsx` (e.g., `// ── Load VRM ─────────`)
     - `Backend/src/services/facialService.ts` (e.g., `// ─── Types ──────────`)
     - `Backend/src/routes/auth.routes.ts` (e.g., `// ─── LOGIN ───────────`)
     - `Backend/src/routes/company.routes.ts` (e.g., `// ─── TEAMS ───────────`)
   - Issue: Extensive use of box drawing and dash banners (`// ───`) across controllers, services, and components.
   - Violation: `antislop-code` decorative separator rule.
   - Recommendation: Replace with concise single-line comments or standard JSDoc section documentation.

8. **LOW - R-29: Palette proliferation via 17 theme presets.**
   - Location: `Frontend/components/ThemeProvider.tsx` and `Frontend/styles/globals.css`
   - Issue: 17 themes are registered (including Cyberpunk, Dracula, Insta Twilight, Cerebras Coral), requiring over 800 lines of custom CSS variables in `globals.css` that are rarely used or tested.
   - Violation: R-29 (Color palette constraint) and R-34 (Every theme shipped must work).
   - Recommendation: Retain core themes (Light, Dark, System) and remove speculative novelty themes.
